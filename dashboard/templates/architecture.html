HoneyTrap AWS Cloud Network Topology

Isolated 3-Subnet Architecture with One-Way Forensic Flow

Public Management Subnet

10.0.1.0/24

  • Bastion Host (Admin access on Port 2222)
  • Nagios Core (Continuous Health & Attack Polling)
  • Puppet Master (Declarative drift correction)
  • Ansible Controller (Orchestration & recovery)
  • Threat Dashboard (Port 5000)

Honeypot DMZ Subnet

10.0.2.0/24 (Isolated)

  • Cowrie SSH Trap (Lure Port 22 open to internet)
  • Fake Web Admin (Port 8080 bait)
  • Strict NACL: ZERO ingress/egress to Prod Subnet
  • Outbound Filter: Outbound scanning blocked
  • NRPE Agent: Monitored via Port 5666

Private Production Subnet

10.0.3.0/24 (Zero Internet)

  • Internal Enterprise App (Protected Port 80)
  • No Public IP (Completely unroutable from internet)
  • Key-only SSH (Port 2222 from Bastion only)
  • fail2ban & auditd active and enforcing
  • Weekly Auto-Patching via Ansible
